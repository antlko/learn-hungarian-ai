# DESIGN SPEC — lively redesign (owner request, round 4; research by researcher a513f3f8466d81452)

Owner: "more lively and colourful design: soft coloured cards, progress rings, small illustrations, activity bars,
a right-hand statistics column when it fits; keep the round-node path (not necessarily a snake); work on colours,
pictures, animations in ALL workflows. Next unit must look CLOSED until >=70% of the previous unit's words are settled;
progress shown as a gently animated ring + percent: red when nothing is learned → blue → green; at >=70% ask
'ready to move on and add new words?'". Reference: a course dashboard with coloured course cards + progress rings,
planning list, right column of statistic tiles and an activity bar chart.

## Decisions (orchestrator; supersede the conflicting repo rules, which must be AMENDED in docs/ADRs)
1. Palette A "Kalocsa & Balaton" (research-measured, hand-computed ratios — re-verify with a script):
   light: bg #FBF7EF, card #FFFFFF, ink #1E2A32, primary #1D5C6E (teal-blue), accent/paprika #B8402A (GRAPHICS ONLY, never text on tints),
   tints cream #FBEFD9 / mist #DCEBEF / blush #F7DCD2 / sage #DDEBDD, success #236B43, warn #8A5F00, error #B3261E, info = primary.
   Ring ramp: #B8402A (vermilion) → #2A6FB0 (blue) → #1B8A6B (teal-green). Warn text fails 4.5 on blush, accent text fails on blush/sage → use ink there.
   Dark theme: derive equivalents (research: card #13181E, ink #F4EBDD, primary #7CC4D4, accent #E8836A); dev must compute and validate ALL pairs.
   Colour is never the only cue: ring has a numeric % label, a state word for screen readers, and a check at settled.
2. Radius 0.875rem (lg=14px, xl=18px), tiles 12px, chips pill. Coloured cards = tint fill + 1px tinted edge, NO shadow; keep `--elevation-raised` for the single primary object.
   Spacing 4px base; card padding 20–24px; gaps 16 (mobile) / 24 (desktop). Stat numerals text-3xl tabular-nums.
3. Layout: shell container becomes max-w-5xl (1024px) for ALL pages (identical outer padding/edges everywhere). Dashboard pages (Today, Progress) use the full width; form/reading pages (Settings, Users, Library, Resources, Listen, Ear, Review start…) keep a centred narrow column via ONE shared class `.page-narrow` (mx-auto w-full max-w-3xl). Reader keeps its wide mode.
   Today ≥1024px: two columns — path column (≈640px, centred in its column) + sticky stats column (320–360px). <1024px: stats collapse to a 2×2 strip ABOVE the path (compact).
4. Stats column (Today) — derived measured facts only, none of them reward points: «К повторению» (due now + new today) as a tinted card with the «Повторить» button inside (the Review tab keeps its own; this is a shortcut); «В колоде» by stage (новое/учу/повторяю/закреплено) as 4 small chips/bars; «Серия» (obligations-met streak); «Уровень» A1.1 with «≈N% слов текста»; a 7-day activity mini bar chart (minutes/day) with text labels and NO goal line/score. Counts may go down; nothing only-rises.
5. THE PATH keeps round nodes (zigzag OK), but nodes now have the ring: ProgressRing (unit's settled/total) around each started unit; animated stroke (700ms cubic-bezier(0.2,0,0,1)); colour by share: vermilion (0) → blue (~0.35) → teal-green (≥0.7), centre shows % (small) or check at ≥70%. Closed units (previous <70% settled and not yet opened): grey node + lock icon; tapping opens the unit page with a notice «Сначала закрепите «<prev>»: N% из 70%» and a secondary «Открыть всё равно» (enrols) — SOFT gate, never refused. At ≥70% settled on the CURRENT unit show a friendly prompt card «Готовы к следующему разделу? Добавим новые слова» [Открыть следующий] [Позже].
6. Motion (transform/opacity only, EXCEPT the ring's stroke-dashoffset which gets a documented exception): ring fill 700ms; count-up ≤600ms (off under reduced motion); current node halo pulse ~2.4s via opacity/transform on a pseudo-element; settle = ring completes then check draws 240ms, no confetti; route change fade + 6px rise 160ms (reuse `card-in`); skeleton shimmer translateX 1.4s; cards in a grid enter with a ≤40ms stagger (max 6). prefers-reduced-motion: everything jumps to final state.
7. Illustrations: small inline two-tone SVGs (line = currentColor/primary + 12–18% tint, no gradients, <2KB each, theme-aware via CSS vars, aria-hidden, decorative): Chain Bridge (Library empty), Parliament dome (Grammar not-started/empty), Tram 2 + Danube ground line (Today header strip), thermal-bath cupola (Today «nothing due» rest state), paprika string (Words empty), Balaton waves (Listen/Ear empty). Also keep existing one-colour pieces. NEVER on a graded card, a Note, the Progress screen's metrics, or as a measure.
8. Documentation/ADR amendments REQUIRED in the same change: docs/UX.md §14.1 palette, §14.3 (ring stroke exception), §14.5 (a ring is allowed ONLY for a derived share with a counted denominator and a numeric label — unit settled share; never streak/XP/«activity rings»), §14.7 (ring ramp uses a dedicated ember→blue→green ramp, `destructive` stays for real failure), §14.9 (two-tone decorative illustrations allowed in the listed places); CLAUDE.md invariants (“Drawings are chrome” + “no levels/rings” sentences) updated accordingly; new ADR (next free number) "Lively redesign: palette A, rings, two-tone illustrations, soft unit gate presentation".
9. Not changing: copy rules (short human copy, InfoTip), accessibility (focus rings, ≥4.5 text, ≥3 UI), data semantics, invariants about FSRS/state spaces.

## Decisions
1. LEVEL / "SCORE" — computed per request, never stored. Counted lemma = status `known`, or has a graduated card (state Review) with retrievability >= mining.knownThreshold. Learning-step words do not count (so numbers can go DOWN: competence signal, not points).
   - "Score" = TEXT COVERAGE = sum(freq_pm of counted lemmas) / sum(freq_pm of all frequency-ranked pack lemmas). ru «Понимаете ≈71% слов обычного текста», en "≈71% of the words in everyday text". Never called points/score in learner copy.
   - Level: per band L (A1..C1): share_L = counted lemmas with cefr=L / pack lemmas with cefr=L. L reached when share_L >= 0.80 AND >= half of L's drillable topics are interleaved|mastered (band with no drillable topics passes) AND L not in BlockedLevels.
   - Sublevel: working band W = first band not reached; p = min(1, share_W/0.80); sub = 1+floor(min(p,0.999)*3) -> "A2.2". If vocab ok but grammar missing, stays .3 and copy names grammar.
   - Confidence: "low" (мало данных) below 100 counted lemmas, else "estimate" (ориентировочно). Never "high".
   - Method sentence (fixed i18n): "estimate from vocabulary and grammar; CEFR bands come from word frequency, not an exam; may be off by a sublevel or two."
   - Names: ru «Уровень (оценка)», en "Estimated level". New pure `stats.EstimateLevel(bandCounts, bandSizes, topicPhases, blocked)`; band sizes + freq_pm sum cached per boot; constants in `stats`, named in ADR. Remove hardcoded chart targets at handlers_progress.go:172 in favour of stats.Specs.
2. ROADMAP replaces Plan, on Today. `course.Resolve`: next = first unit that is enrolled and not done; else first unit neither enrolled nor done. Reader words still make a unit done but cannot move next away from an enrolled unit. Path = unit nodes grouped by month, checkpoints m1/m3/m6 as milestone nodes. States: пройден · начат · следующий · впереди. Unit finished mostly via reading (fromHere < wordsInPlay) gets badge «N слов уже из чтения». Nothing locks (ADR-013). Node opens UnitDetail (bottom sheet mobile / side panel desktop). Reader words get own «Из чтения» card (due+new, link scope=reader), never nodes. `/plan` redirects to `/`.
3. GRAMMAR uses same node vocabulary; topics grouped by CEFR. Plain phase names: только правило (explained) · ещё не начато · тренируем по одному (blocked) · вперемешку (interleaved) · освоено. Lock icon only for failed checkpoint. Topic page tabs Урок | Упражнения (ADR-043 decides which opens). Gate shows "точность ≈72%, нужно 80%; ответов 14 из минимум 20". Remove duplicate rail map -> back + prev/next topic.
4. LEARNING STEPS: NO change to FSRS/config (would break replay). Copy: "a miss doesn't erase the word: it comes back in about a minute, then about 10. A word you already knew keeps part of its memory strength." «Как это работает» dialog on review start + card: stages, what each button schedules, no N-in-a-row rule, set summary (missed listed not re-asked), «Знаю».
5. WORDS: WordRow gains stage ("learning"|"relearning"|"young"|"mature"|"known"), intervalDays, reps, stepsLeft, stepsTotal from strongest card via srs.Memory rules; `?stage=` filter. Pagination stays in Go.

Review on touch: grade buttons >=48px sticky bottom with safe-area padding; KeyBar hidden on (pointer: coarse)/<md; rails fold into disclosure; accent strip (á é í ó ö ő ú ü ű) above answer input; input autocapitalize=off autocorrect=off spellcheck=false. No swipe gestures.

No due forecast.
8. SIDECARS: nlp = build opt-in (python:3.12-slim, spaCy 3.8.x, hu_core_news_md 3.8.1; ~2.4GB RAM unmeasured — tell owner it is NOT a small container). Model downloads on /warmup with progress in /health (like mt). 9. INSTALL FROM UI: pack = GitHub Release asset `langpack-hu-v1.sqlite.gz` built `--subtitle-sentences 0` (Tatoeba+Wiktionary, CC BY-SA). Config `langpack.url`, `langpack.sha256` (defaults as constants in internal/config, also in clone.go; only via updateConfig; URL never from request body). Admin job: download to `<data>/langpack-hu-v1.sqlite.part`, sha256 of compressed stream, gunzip, open + schema check, ID-COMPATIBILITY CHECK (every lemma_id in lemma_state/note etc. maps to same (lemma,upos) in new pack; else refuse), atomic rename. Failure: delete .part, state failed + i18n key, current pack untouched; disk-full its own key. Restart: Dockerfile sets TANULOM_SUPERVISED=1; POST /api/admin/restart 202 then SIGTERM self (graceful), `unless-stopped` relaunches; without var button reads «Остановить сервер». README `docker run` gains `--restart unless-stopped`. Sidecars: docker socket rejected; Settings «Компоненты» screen: card per component (human description, RAM, state не настроен/нет связи/загружает модель x%/готов, copyable `docker compose --profile X up -d`, URL field, «Проверить»).
10. CONTENT: no LLM-authored Hungarian sentences as material. Developer writes word lists+glosses only; sentences from pack. Course keeps 24 units (course ends) growing 853 -> ~1,400 words, preferring top-2000 lemmas not covered; every word in starter dictionary; >=90% clozeable from starter sentences (validator). 12 themed side units (~40 words each) `course_unit.track`='theme' (default 'core'), drawn as side branches: числа и счёт, время и часы, дни/месяцы/даты, цвета, тело, погода, еда, одежда, дом, поездки, чувства, хобби. Up to 4 new grammar topics (numbers/time first: counting+ordinals, -kor/óra/fél/negyed, dates -án/-én), check not already in curriculum.py; lessons >=800 chars; drills only where a generator applies else `explained`. ~30 «подборки живых примеров» (10 A1, 12 A2, 8 B1; 20-30 Tatoeba sentences each, all lemmas <= level), built by pipeline, importable into library by one click.
11. PERF: lazy-load inactive locale (i18n.ts); inPlaySet returns its error; benchmark recordInteraction on 5k-card deck, optimise only if >20ms and never throttle (due_left must stay fresh); no manualChunks without measurement. (handlers_words.go:100-106 "rows not closed" is NOT a bug.)
12. LOOP CHANGES: one-next-action home; coverage as headline progress; typed production on mobile via accent strip; numbers+time early; real-sentence sets for input before texts.

# PDF provenance ledger

Copies of papers held locally for reference. **Redistribution status is tracked per file** —
some of these may be read but not republished.

## Rules

1. **Never commit a paywalled publisher PDF.** A DOI is a citation; a mirrored paywalled PDF is
   a liability. Files marked `no` below are gitignored (see `.gitignore` in the repo root).
2. **Every file gets a row.** A file with no row gets deleted.
3. Filenames are prefixed with the citing note's ID: `05-brunmair-richter-2019-interleaving.pdf`
   is cited by `../05-interleaving.md`.
4. When in doubt, link instead of copying. **The notes are written to be complete without the
   PDFs** — they carry the effect sizes, the moderators and the conclusions inline.
